# IB 포털 사용 안내

기업금융(IB) 서비스 소개와 자금조달 학습용 부서 포털입니다. 서버 없이 `index.html` 파일 하나로 동작합니다.

## 1. 폴더 구성

```
부서포털/
├── index.html                       포털 본문 (구 부서포털_v2.html)
├── README.md                        이 안내서
├── files/
│   ├── ib-service-introduction.pdf  기업금융(IB) 서비스 소개서 (구 IB_서비스소개서.pdf)
│   └── funding-glossary.pdf         기업 자금조달 용어 안내 (구 자금조달_용어안내.pdf)
└── 이전버전/
    └── 부서포털_v2.html              이름 바꾸기 전 원본 사본
```

## 2. 여는 방법

- `index.html`을 더블클릭해 웹 브라우저(Chrome, Edge 권장)로 엽니다.
- 글꼴(나눔고딕)은 인터넷에 연결되어 있을 때 Google Fonts에서 불러옵니다. 연결이 없으면 맑은 고딕으로 표시됩니다.
- 사내 웹서버나 공유 폴더에 올릴 때는 `index.html`과 `files/` 폴더를 함께 올립니다.

## 3. 화면 구성

| 메뉴 | 내용 |
|---|---|
| 홈 | 포털 소개, 조달 방법 비교·계산기 바로가기 버튼 |
| 사업 영역 | ECM·DCM, 부동산 PF·Structured Finance, M&A 인수금융·자문 |
| 조달 방법 | IPO·유상증자·회사채·CP를 성격·소요 기간·장단점으로 비교한 표 |
| IPO 절차 | 사전 진단부터 상장·사후관리까지 6단계 |
| PF 구조 | PF·유동화 구조도 (각 상자를 누르면 참여자 역할 설명이 나옴) |
| 트랙레코드 | 연도·유형별로 거를 수 있는 딜 카드 |
| 계산기 | 회사채 이자비용 계산기, PF 지표 계산기(LTV·DSCR) |
| FAQ | 키워드 검색, "모두 펼치기" 버튼 |
| 자료실 | files 폴더의 PDF 2종 목록과 다운로드 |

- 화면 폭이 좁으면(980px 이하) 메뉴가 ☰ 버튼으로 접힙니다.
- 계산기에 넣은 값은 브라우저 안에서만 계산하며, 어디에도 저장하거나 전송하지 않습니다.

## 4. 내용을 고칠 때 확인할 점

- **트랙레코드 카드는 예시 데이터입니다.** 실제로 게시할 때는 공시로 확인된 딜만 넣고, 법무·준법감시 확인을 거쳐 바꿔 주세요.
- **준법 심의 번호:** 화면 하단과 내려받는 소개서의 "준법감시인 심의필 제○○호"는 아직 비어 있는 자리입니다. 심의를 받은 뒤 실제 번호로 바꿔 주세요.
- **자료실:** `files/` 폴더의 PDF를 목록으로 보여 줍니다(파일명·설명·용량·다운로드 버튼). 버튼은 `files/파일명` 상대 경로 링크이고, `download` 속성으로 한글 이름(`IB_서비스소개서.pdf`, `자금조달_용어안내.pdf`)으로 저장됩니다.
  - 바로 저장되는 동작은 포털을 **웹서버(http/https 주소)로 열었을 때** 적용됩니다. `index.html`을 더블클릭해 열면(`file://`) 브라우저가 `download` 속성을 무시하고 PDF를 같은 탭에서 엽니다.
  - 자료를 추가하거나 바꿀 때는 `index.html`의 `<ul class="file-list">` 안에 항목을 하나 더 넣고, 파일명·설명·용량(KB)·`download` 이름을 직접 고쳐야 합니다(자동으로 목록을 읽지 않음).
- **파일 이름:** 파일을 추가할 때는 한글·공백 없이 영문 소문자와 하이픈(-)만 씁니다(예: `ipo-checklist.pdf`).

## 5. 디자인

색·글꼴·여백 기준은 '우리 부서 포털' 디자인 시스템을 따릅니다. 같은 폴더의 `부서포털_v2_시안A·B·C`와 `부서포털_v2_우리부서포털.html`은 색 시안 파일이며, 포털을 운영하는 데 필요하지는 않습니다.
